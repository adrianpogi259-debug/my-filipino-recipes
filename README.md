# Pinoy Kusina — Filipino Recipes

A beginner-friendly recipe website built with HTML and CSS for an HTML Foundations practical exercise.

## Pages
- `index.html` — homepage, featured recipes, recipe comparison table and recipe images
- `recipes/chicken-adobo.html` — Chicken Adobo recipe
- `recipes/sinigang.html` — Sinigang na Baboy recipe
- `recipes/pancit-canton.html` — Pancit Canton recipe
- `feedback.html` — accessible feedback form
- `thank-you.html` — form confirmation page
- `styles.css` — shared responsive styling

## HTML features demonstrated
- Semantic structure: `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
- Headings, paragraphs, ordered lists, and unordered lists
- Internal links and images with alternative text
- A data table with caption and scoped headers
- A labeled form with text, email, select, radio, checkbox, and textarea controls
- Recipe images with descriptive alternative text
- Skip link, descriptive page titles, language declaration, and responsive viewport

## Run locally
Open `index.html` in a web browser. No build tools are required.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Wait for GitHub Pages to publish the site.

## Notes
This is a static HTML/CSS learning project. The feedback form is a demonstration and does not store or send submissions. Recipe images require an internet connection.
