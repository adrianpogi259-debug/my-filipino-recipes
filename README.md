# Pinoy Kusina — Filipino Recipes

A beginner-friendly Filipino recipe website built for an HTML Foundations practical exercise.

## Pages

- `index.html` — homepage with featured recipes, a comparison table, and navigation
- `recipes/chicken-inasal.html` — Chicken Inasal recipe and embedded cooking video
- `recipes/laing.html` — Laing recipe
- `recipes/tortang-talong.html` — Tortang Talong recipe
- `feedback.html` — front-end demonstration feedback form
- `styles.css` — shared responsive styling

## HTML features demonstrated

- Semantic page structure using `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
- Headings, paragraphs, ordered lists, and unordered lists
- Internal navigation links and images with alternative text
- A data table with a caption and scoped row and column headers
- A labeled feedback form with text, email, select, radio, checkbox, and textarea controls
- An embedded YouTube video on the Chicken Inasal recipe page
- Skip links, descriptive page titles, a language declaration, visible keyboard focus styles, and responsive layout rules

## Feedback form note

The feedback form is a front-end demonstration only. It displays a confirmation message but does not send responses to a server or store them.

## Run locally

Open `index.html` in a web browser. No build tools are required. Images and the embedded video need an internet connection.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Wait for GitHub Pages to publish the site.

## Image credits

Recipe image attribution and license links are shown beside the images on their respective recipe pages. Check the linked Wikimedia Commons file pages for the current license and attribution details.
